## 一、通用版（B 站动态 / 即刻 / V2EX / 知乎想法 / 朋友圈）

**手势视频控制 v1.3.0 发布了**

一句话：用摄像头比手势控制网页视频，不用找遥控器、也不用碰键盘。

比什么手势管什么：
- 👌 OK → 播放 / 暂停
- 🤙 单个小拇指向上下 → 音量加减
- ☝️👇 单个食指朝上下 → 上一集 / 下一集
- 🖐️ 手掌张开 2 秒 → 切换长视频 / 短视频模式
- 👍 点赞、👍👍 一键三连、6️⃣6️⃣6️⃣ 锁定手势、🤟 刷 B 站「换一换」

这一版重点修了两个"体感很差"的地方：

**1. 识别更准了。** 之前判断"手指伸没伸直"的方法在"手掌正对镜头"时会失效——蜷起来的手指会被当成伸直的，所以你会遇到"比一个手势却出来另一个"。这版换成了看关节角度 + 结合 3D 坐标，手歪一点、转一点、离远一点都认得出。

**2. 不会再用着用着就不理你了。** 以前关掉弹窗看视频，过一会儿手势就没反应，得点一下插件才回来（后台被浏览器回收了，而旧版没有任何代码去把它救回来）。现在后台每分钟自检一次，断了自动重建，页面上会提示"已自动恢复"。

另外三个新增：
- **没在看视频的时候，音量 / 切集 / 点赞这些手势不再乱触发**（顺手修掉了"在 B 站首页比 1 选视频，却被当成上一集"）
- **插件里能直接翻手势表了**：弹窗底部、悬浮面板标题栏点 📖
- 已适配 B 站 / YouTube / 抖音 / 腾讯视频 / 爱奇艺 / 优酷 / 西瓜 / 芒果，其它网站也能用

下载：GitHub Release 里下 `.crx`，拖进 `chrome://extensions`（要先打开右上角"开发者模式"）；也可以下源码用"加载已解压的扩展程序"。

仓库：https://github.com/yidiqingyu/gesture-video-control
Release：`<Release 链接>`

免费开源（MIT）。摄像头画面只在你自己电脑的浏览器里处理，不上传；也没有申请全站权限。

## 三、技术向（V2EX / 知乎 / 掘金 / 少数派）

**标题建议**：《手势视频控制 v1.3.0：把"手势判定"重做了一遍，顺手做了断线自愈》

用 MediaPipe Hands 在浏览器端做手势识别、控制网页视频的 Chrome MV3 扩展，这版把三个债还了。

**1. 判定核心重写（精度）**

旧版用手指的"距离比值"判断伸没伸直：`指尖到指根 ÷ PIP 到指根 > 1.25` 就算伸直。

问题在于：手掌正对镜头蜷手指时，手指是朝镜头方向弯的，PIP 在画面上几乎和指根重合，分母趋近 0 → 比值暴涨。我用正运动学合成了一只手做离线实测，**蜷曲的中指该比值是 7.6**（门槛只要 1.25）——蜷着的手指被稳稳判成"伸直"。这也解释了为什么以前会"比 A 出 B"。

新版改成：
- 以 **PIP 关节夹角**为主特征（伸直≈180°、蜷曲≈50°），投影不会说谎；
- 归一化坐标先做**宽高比校正**（x 按宽、y 按高，直接算距离本身就失真）；
- 再和 MediaPipe 的**米制世界坐标**各算一遍取平均；
- 方向判定改成**竖直圆锥**：手指与竖直方向夹角超过 55° 就判"方向不明"、宁可不动作（治的是"音量/切集方向乱跳"）；
- 容易混的手势之间留**死区**（例如"数字 4"和"手掌张开"只差拇指，拇指半伸时不猜）。

**2. 断线自愈（稳定性）**

MV3 的 Service Worker 空闲约 30 秒会被浏览器回收，离屏识别页也可能被关掉，或者因为它是"不可见页面"被冻结/降频。旧版**没有任何代码会去重建它**（所以现象是"开着弹窗就正常、关掉过一会就失灵"）。

现在后台用 `chrome.alarms` **每分钟自检**：
- 离屏识别页还在不在、有没有响应；
- **帧数还在不在涨**（不涨 = 循环卡死或被冻结）；
- 控制目标标签页还在不在（用手势关掉当前页面后要重新指向）；
- 页面脚本还响应吗（不响应就补注入）。

异常就 `closeDocument()` + 重建离屏文档、用持久化的设置重启引擎；重启后**再探一次确认真的起来了**才通知用户；连续 3 次救不回来就停止折腾并提示查摄像头。控制器侧还加了 Web Lock（防不可见页面被节流/冻结）和摄像头看门狗（`track.onended`、画面 `currentTime` 不前进就自动重开）。

**3. 动作闸门（别乱触发）**

新增一张纯逻辑的判定表，把手势动作分三类：
- **观看类**（播放暂停/音量/切集/点赞/三连）：页面上必须真的在放视频；
- **信息流类**（短视频模式 ↑↓）：页面上至少要有视频元素；
- **页面类**（B 站首页数字选视频/换一换/666 锁定/关闭页面）：随时可用。

闸门统一放在动作出口，任何分支忘了判断也漏不掉；探测不到页面状态时**放行**（不能因为探测失败就把扩展变成不响应）。

**测试**

用正运动学合成手做离线断言，**582 项自测全绿**：判定 229 / 引擎时序 13 / 自检决策 44 / 动作闸门 90 / 静态体检 206（含接口一致性、权限与站点清单、编码体检、打包清单）。改阈值前先跑 `node tests/run-all.mjs`。
