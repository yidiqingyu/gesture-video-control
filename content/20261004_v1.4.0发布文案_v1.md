正文：

```markdown
这一版是**界面重做**：四处界面（弹窗 / 悬浮窗 / 授权页 / 页面内悬浮面板）以前各写各的配色，
现在收成一套设计语言，并且支持深色 / 浅色双主题。

## 新增

- **手动切换深浅色**：弹窗、悬浮窗、页面内面板的标题栏上都有一个小图标，点一下换主题：
  `跟随系统 → 与系统相反 → 与系统相同 → 回到跟随系统`。
  从默认状态点第一下颜色一定会变，连点三下回到「跟随系统」。选择会被记住，
  三处界面实时同步（在弹窗里换了，页面内那块面板立刻跟着变）。
- **深浅双主题**：默认跟随系统。摄像头画面两种主题下都保持深色（视频本身发光，浅底反而刺眼）。

## 改进了什么

- **统一设计语言**：一套颜色令牌 + 单一强调色（电光蓝）；卡片改成「1px 描边 + 顶部高光」的玻璃感；
  状态行改成「彩色圆点 + 文字」，不再用整块色块。
- **图标换成矢量图**：logo、眼睛、最小化、关闭、手势表这些不再用 emoji（各系统画出来粗细不一致，
  放深色卡片上很"玩具"），统一成一套线宽一致的 SVG，颜色自动跟随主题。
- **页面内悬浮面板从白底改成深色玻璃**，和弹窗终于是一套了。
- **科技感细节**（克制）：摄像头画面加了四角取景框和一条缓慢上移的扫描线；识别中时悬浮球绿点会缓慢呼吸。
- **键盘可用**：焦点环、`Esc` 之类按浏览器的来；系统开启「减少动态效果」时，所有动画自动关掉。

## 修好了

- 页面内面板「正在打开摄像头预览…」这行字会被挤成**竖排**（旧版本就有，一直没人放大看过）。

## 安装 / 升级

- 已经装过的话：下载下面的 `.crx` 拖进 `chrome://extensions` 即可**覆盖升级**（扩展 ID 没变，设置和授权都保留）。
- 第一次装：先打开 `chrome://extensions` 右上角的「开发者模式」，再把 `.crx` 拖进去。
  也可以下载源码用「加载已解压的扩展程序」。
- 还没上架 Chrome 应用商店，所以会提示「非应用商店来源」，这是正常的。

## 说明

- 免费开源（MIT）。摄像头画面**只在你本机的浏览器里处理**，不上传；也没有申请 `<all_urls>` 之类的全站权限，
  只有视频站点的固定权限 + 你主动点击时的 `activeTab`。
- 支持 B 站 / YouTube / 抖音 / 腾讯视频 / 爱奇艺 / 优酷 / 西瓜视频 / 芒果 TV。

**完整改动**：[`2f95f4e...v1.4.0`](https://github.com/yidiqingyu/gesture-video-control/compare/2f95f4e...v1.4.0)
```

### 技术向（V2EX / 知乎 / 掘金）

**标题建议**：《手势视频控制 v1.4.0：把四处界面的配色收成一套设计令牌，顺手做了深浅双主题》

可以展开讲的点（都在 README「界面与主题」一节里）：

- 为什么单独搞一个 `theme.css`：原来是四个界面各写各的色值，改一个颜色要改四处。现在只写 `var(--gvc-*)`。
- 弹窗/悬浮窗直接 `<link>`，**页面内面板（Shadow DOM）靠 `content_scripts.css` 注入页面 `:root`**，自定义属性继承进去 —— 所以那份文件里只允许有 custom properties 和属性选择器，绝不写元素选择器（否则会污染 B 站 / YouTube 的样式）。
- 双主题怎么做的：默认那层是 `@media (prefers-color-scheme)`（纯 CSS，JS 没跑起来也不闪错色），手动选择那层是 `[data-gvc-theme]` 属性选择器盖掉它。代价是浅色值写了两遍，**静态体检会逐条比对两处**，防走样。
- 页面内面板**不碰网站 DOM**：属性写在面板自己的宿主元素上，宿主自己的声明盖过从页面继承来的值。
- 主题按钮为什么是三态循环、而且顺序随系统换向（自测里专门有断言：从默认状态点第一下外观一定变、连点三下回到跟随系统）。
- 顺手踩的坑：`git reset --hard` 在 `core.autocrlf` 下把工作区检出成 CRLF，导致测试里带 `\n` 的正则全部匹配不上 —— 这条现在也有自测盯着。
